二、新增功能(阶段 7–8)

交互纵深

  • 焦点模式：选中笔记后 0.85s 三次缓动飞行到该笔记(相机 + controls.target 同步 lerp)。
  • 峰到路径：点击峰标签高亮峰值并绘制峰内笔记的金色连线(#d7c27e, DynamicDrawUsage)。
  • 对比模式：在项目概览选择时间基准层，即时显示新增/消失笔记计数(±delta)。
  • 笔记编辑：详情面板内联编辑标题/正文/标签,保存后按稳定 ID 重分析。
  • 增量合并：工具菜单导入既有项目后,再导入新笔记按 ID 去重合并到当前项目。
  • 复盘报告：导出 Markdown 复盘报告(峰值 → 覆盖笔记 → 完整清单)。

健壮性(阶段 5–6)

  • 3D 与 2D 等高线双视图,WebGL 不可用时自动降级到 2D。
  • 模型不可用时明确标记「降级」后切换为确定性本地向量。
  • 编码/导入多格式(JSON/CSV/TSV/Markdown/YAML)；项目自动保存 IndexedDB。
  • 代码拆分:three 与 Terrain3D 独立懒加载 chunk；transformers 仅在分析 Worker 语义路径加载。
  • CI:typecheck / lint / unit / build / size:check / e2e / a11y / visual 全套质量门。
